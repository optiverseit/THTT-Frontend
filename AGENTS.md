# Project Rules & Agent Instructions

## ⚠️ STRICT ENVIRONMENT FILE POLICY
- **STRICTLY DO NOT TOUCH OR UPDATE `.env`, `.env.production`, OR `env.production` BY YOURSELF.**
- These environment files contain production credentials, SMTP passwords, and server URLs managed exclusively by the human administrator.
- You may **read** `.env` or `env.production` if needed for reference, but you must **NEVER modify, edit, overwrite, create, or delete** them under any circumstances.
